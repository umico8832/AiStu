# Kaleidoscope 桌面 MVP 范围

> 状态：当前交付范围
> 最近复核：2026-07-25
> 本文定义“做什么”和“怎样算完成”，不记录完成进度。真实状态见
> [`ROADMAP.md`](ROADMAP.md)。

## 1. 阶段目标

证明一条稳定、可演示的教学闭环：

> 学习者在桌面对话中提出困惑，AI 基于可靠知识选择已有课件并生成受约束场景；
> 对话先显示建议，学习者明确确认后才打开课件。预测与操作形成结构化事件，
> 在学习者下一次明确发送消息时参与同一会话的后续教学。

本阶段优先保证闭环、安全和教学质量，不追求课程数量、社区规模或商业化成熟度。
黑客松最终交付是 GitHub 上可运行的 macOS arm64 应用和完整演示视频。

## 2. 黄金场景

第一条完整场景是“递归阶乘中的函数调用栈”：

```text
“我知道递归函数会调用自己，但不明白调用栈到底怎么变化。”
→ AI 识别入栈、等待与返回顺序的困惑
→ 推荐调用栈课件
→ 用户确认
→ 观察并预测递归进入、基例和逐层返回
→ 交互结果回到同一对话
```

现有 `call-stack-visualizer` 原型（已迁移至 `packages/lessons/call-stack`，原型目录已删除）是
迁移来源，必须复用其已验证的组件职责、动画和教学逻辑。

## 3. 范围内能力

### 3.1 桌面运行时

- Electron 主对话窗口与至多一个活动课件窗口；
- electron-vite、electron-builder 与 pnpm workspace；
- Node.js 22.21.0 或 24.14+、React 19、TypeScript strict、Tailwind CSS 4；
- Main / Preload / Renderer 安全分层；
- 开发、构建、macOS arm64 打包和启动验证；
- 固定依赖版本与可复现锁文件。

### 3.2 AI 对话

- 单屏空状态、消息列表、输入草稿和最近会话；
- 发送、流式展示、停止、重试、错误与取消状态；
- 最多 30 个本地会话，新建和切换不覆盖历史；
- 会话、流式生成、可视化和应用 UI 状态分离；
- AI 文本与结构化 TutorCommand 分离；
- 受限 Markdown 展示，不执行模型提供的 HTML；
- DeepSeek API Provider、本机 Codex CLI Provider、确定性 Demo Provider，以及
  不耦合 UI 的 Provider 抽象；
- DeepSeek Key 只通过项目根目录 `.env` 或启动环境进入 Main，不进入 Renderer、
  应用持久化数据或日志。

### 3.3 知识检索与课程学习

- Main-only `KnowledgeService` 读取并校验 `rag/chunks.jsonl`；
- 中文 n-gram、英文 token 与轻量 BM25 检索；
- 每轮只注入少量相关片段，并把知识 chunks 当作不可信参考数据；
- 引用 ID 必须属于本轮候选集合；
- `grounded`、`not_found`、`not_required`、`unavailable` 状态；
- 引用与消息一起持久化，重启后仍可查看；
- 发布包携带经过校验的运行时知识快照；
- 内容商店与社区复用稳定的全国考试目录；
- 商店首页只展示考试一级目录，卡片使用独立“进入”按钮打开二级课程目录；
- 商店基础搜索按考试名称、简称、类别、描述和旗下科目做本地过滤，并提供清空与
  无结果状态；
- 只有完成第一方内容接入的课程可以“开始学习”；目录中尚未接入学习内容的课程使用
  独立“添加到课程库”操作展示，不复用直接学习逻辑；
- 408 数据结构课程页展示 7 个模块、122 个原子知识点、搜索、标准定义和受控
  思维导图；
- 用户可从课程页启动独立专项会话；
- 专项范围约束 RAG、Tutor 和课件选择，并持续显示；
- 首次专项进入提供一次性、无分数的轻量起步引导；
- 每门专项独立记录前台有效学习时长、学习日期、专项次数、已接触模块与知识点、
  课件完成和预测结果；
- 课程页与专项会话共享学习足迹入口，并渐进展示进度与成就；
- 预测错题与对话误解自动收录进课程错题本，可从课程页一键开启带错题上下文
  的复盘会话；跨会话重新预测正确自动标记已复盘，对话误解可手动标记；
- 成就只由真实学习、合法知识引用和课件交互证据触发；
- 教学采用“人话结论—具体小例子—单一记忆点”，小题只在自然检查点出现；
- 学习者表示不会时先用浅显类比入门，并明确类比与真实概念的对应关系；
- 用户表示看不懂时缩小例子、减少术语，当轮不继续出题；
- 除已有明确课件操作外，每轮优先提供 2–4 个经过 Schema 限制的引导选项，让
  学习者无需输入文字也能继续、换比喻、尝试小题或跳过。

当前不引入向量数据库、embedding 服务或大型 Agent/RAG 框架。

### 3.4 互动课件与可视化运行时

当前首批资源共 10 项：

| 资源组 | 课件 |
| --- | --- |
| 黄金场景 | 递归调用栈 |
| ODS | ArrayStack 按位插入、ArrayQueue 循环数组、DualArrayDeque 再平衡 |
| 408 核心过程 | 二叉树遍历、图遍历、折半查找、AVL 旋转、KMP、快速排序划分 |

每项课件必须具备：

- 静态注册 ID、版本、真实知识点绑定和审核状态；
- 课件专属严格 Schema 与可靠默认场景；
- 前进、后退、重置、预测交互和 reduced-motion；
- 只读教学材料，不开放代码编辑；
- lazy load、错误边界和非法输入降级；
- 结构化步骤、预测、重试、完成和关闭事件；
- 独立教学审查后才能标为 `reviewed`。

课件开发与审核要求见
[`guides/LESSON_DEVELOPMENT.md`](guides/LESSON_DEVELOPMENT.md)。

### 3.5 AI 调整已有课件

AI 只能选择已注册的 `visualization_id`，并输出：

- 通过课件 Schema 的 `VisualizationSessionSpec`；
- 与当前 session ID、visualization ID、base revision 匹配的
  `VisualizationPatch`；
- 课件预先声明的场景数据、步骤选择、强调、高亮、说明、预测暂停和预定义布局。

运行时必须限制文本长度、步骤数、数值范围、枚举、版本和未知字段。非法 spec 回退
到审核过的默认场景；非法或过期 patch 保持当前页面不变。

AI 不得输出或指定任意源码、HTML、CSS、组件路径、文件路径、URL、属性路径或
可执行内容。

### 3.6 独立窗口中的单一活动课件

- `open_visualization` 先生成对话建议卡，不直接打开；
- 用户确认后才校验并创建或替换 session；
- `visualizationStore` 任意时刻只保存 `activeSession | null`；
- 相同课件在当前页面更新，不同课件原子替换；
- 课件在独立 Electron 窗口中显示，并可切换系统全屏；
- 课件窗口与主对话窗口均可独立移动和操作；
- 对话组件保持 mounted，草稿、消息、滚动和流式状态不丢失；
- Main 只在主窗口与当前课件窗口之间转发经过 Schema 校验的 session、步骤和
  互动事件；
- 课件事件不自动生成用户消息；
- 关闭课件回到同一会话和原位置。

### 3.7 多视角表达

- 同一知识点可使用定义、直觉、流程、对比、做题、易错和可视化等注册视角；
- 切换视角不改写标准定义或知识事实；
- AI 只能选择已声明的视角与安全字段；
- 当前不提供独立个人知识万花筒页面；
- 当前不持久化跨会话掌握度投影。

### 3.8 社区最小闭环

- 社区首页以知识讨论与题库共建动态为主，考试与科目只作为轻量筛选和内容绑定；
- 408、普通高考、考研公共课、四六级、全国计算机等级考试、教师资格考试、成人
  高考和自学考试可作为题库或话题范围；
- 学习者可围绕一个明确知识点发起话题，正文表达自己的判断、疑问或经验；
- 学习者可提交 PDF、Word、WPS、Excel、CSV、JSON、TXT、Markdown 与 ZIP
  等题库文件；当前本地 MVP 持久化投稿元数据和审核状态；
- 解释、类比、易错点、做题方法、考试大纲与复习重点等结构化投稿；
- 每条题库投稿保存文件名、格式、大小、来源说明、作者显示信息、考试 ID、课程 ID、
  内容类型和审核状态；
- 题库投稿至少包含一个受支持文件，单文件不超过 30 MB，一次最多 8 个；
- 模块、科目与分区的一致性校验；
- 待审核、已通过和已驳回三种状态；
- 话题与题库投稿属于社区域，本地受控持久化并迁移旧快照；
- 普通学习者界面只展示审核状态，不暴露审核操作；
- 未审核内容不进入事实型回答；
- 审核通过的社区内容仍带来源，不自动写入标准知识库。

### 3.9 最小持久化

Main 通过版本化 JSON 保存：

- 最多 30 个最近会话、消息与草稿；
- 当前活动会话 ID；
- 每个会话的专项范围与最近可视化快照；
- 课件当前步骤和交互历史；
- 独立的课程起步档案；
- 独立的课程学习足迹、有效时长、内容覆盖和练习证据；
- 独立的课程错题记录（预测错题与对话误解快照、出现次数与复盘状态）；
- 必要 UI 偏好。

读取时使用 Zod 校验并迁移旧版本。Renderer 不直接写文件。课程主观起点不是掌握
证据，也不能混入标准知识对象。学习足迹可以跨同一门专项的会话累计，但只表达
参与、接触与练习，不自动推断掌握。

## 4. 明确不做

- 用户编辑课件代码；
- Monaco、Tree-sitter、ProgramModel；
- 任意 C 或其他语言的动态解析与执行；
- 真实终端、node-pty、xterm.js；
- IDE、LSP 或调试器；
- AI 运行时生成 React 页面或加载远程组件；
- 多个同时活动的课件窗口、多课件标签、并排课件或可视化历史栈；
- 插件系统；
- 云同步与跨设备状态；
- 云端实时多人社区、关注、私信和商业级治理；
- 社区投稿自动进入权威知识库；
- 云端向量库、embedding 管线和跨课程完整 RAG；
- 商业级掌握度判定和自动复习系统；
- 独立个人知识万花筒页面；
- 未经优先级筛选一次实现大量课件；
- Developer ID 签名、公证和 Windows 正式发布作为黑客松阻塞项。

## 5. 安全完成条件

- `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`；
- Renderer 无 Node、文件、进程或凭据权限；
- Preload 不暴露 `ipcRenderer` 或通用 `send/invoke`；
- 所有 IPC 同时校验输入与 sender；
- 权限、外部导航和新窗口默认拒绝或受控；
- AI 输出、知识 chunks 和社区文本均不能注入可执行内容；
- 引用、课件 ID、session、revision 和场景数据全部经过 allowlist 或 Schema；
- 打包版保持与开发版相同的核心安全设置。

## 6. 验收场景

| 场景 | 必须证明 |
| --- | --- |
| 基础对话 | 发送、流式展示、停止、重试、错误恢复、会话切换与重启恢复 |
| 知识回答 | 检索少量候选、显示合法引用、拒绝伪造 chunk、无匹配时降级 |
| 课件建议 | 用户确认前不打开；拒绝不会改变当前 session |
| 黄金课件 | 调用栈场景通过校验，步骤、预测和返回阶段可操作 |
| 页面调整 | 合法 patch 更新同一 session；过期或越界 patch 被拒绝 |
| 事件回流 | 步骤和预测进入教学上下文，但不伪装成用户消息 |
| 生命周期 | 新课件替换旧课件；关闭后对话、草稿和位置保持 |
| 独立窗口 | 课件不覆盖主对话，可进入和退出系统全屏，窗口间只同步受校验的活动 session 与互动事件 |
| 课程专项 | 检索和课件限制在当前课程；退出后保留专项历史 |
| 学习足迹 | 前台有效时长、内容覆盖与课件证据可恢复；成就不由页面浏览触发 |
| 错题复盘 | 预测答错自动收录；复盘会话携带错题快照与课件建议；跨会话答对自动标记已复盘 |
| 社区共建 | 可创建知识点话题并提交多格式题库；投稿带来源和审核状态，错误绑定、危险文本或不支持的文件被拒绝 |
| 安全边界 | Renderer 无 Node，最小 Preload API，IPC、权限和导航受控 |
| 打包交付 | macOS arm64 产物启动并携带已校验知识快照 |

## 7. MVP 完成定义

以下条件必须同时满足：

- 上述范围内能力可在同一桌面应用中走通；
- 10 项首批课件均通过独立教学审查；
- 未知课件、非法场景、过期 patch 和伪造引用会安全失败；
- 知识、社区、用户和会话数据边界没有被绕过；
- typecheck、lint、Vitest、Playwright、build 与 macOS 打包验收通过；
- GitHub Release 提供 macOS arm64 `.dmg` 和 `.zip`；
- 发布产物对应明确 Git commit；
- 演示机器走通对话、引用、确认、课件交互和返回对话；
- 发布 3–5 分钟核心流程演示视频；
- README、架构、范围、路线图和真实实现一致。

当前完成度与剩余交付项见 [`ROADMAP.md`](ROADMAP.md)。
