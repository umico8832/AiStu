## 1. 当前阶段

0.1.0 已经证明桌面对话、知识引用、课件确认、互动和事件回流可以形成完整教学闭环。
项目现在进入 0.2：从可演示原型转向可持续日常使用的个人 AI 学习工具。

开发由一人长期维护。新工作优先考虑真实学习价值、可靠性和维护成本，不再受比赛、
宣传素材或主题表达驱动。

## 3. 当前优先级

### P0：身份与基线迁移

- 全仓库统一为 `AiStu`；
- 替换桌面应用图标；
- 删除旧主题组件、固定展示分类和过期比赛叙事；
- 重新执行完整质量门与 macOS 启动验收。

### P1：日常使用可靠性

- 将 Provider 配置变成应用内可恢复流程；
- 覆盖超时、取消、重试、异常退出与版本升级；
- 提供用户数据导出、备份和恢复；
- 为持久化、迁移和窗口生命周期补充回归测试。

### P2：学习延续

- 从最近会话、课程记录和错题自然继续学习；
- 让复盘会话只带入必要上下文；
- 记录真实重试结果，并保持证据边界；
- 根据现有记录提供可解释的下一步入口。

### P3：教学质量

- 从真实使用中收集失败案例；
- 为 Tutor 决策和知识降级建立回归样例；
- 只针对高频、适合交互的问题新增课件；
- 完成新增 408 知识的独立学科审查。

## 4. 维护状态

内容商店、本地社区、全国考试目录和 Demo Provider 保持可用，但当前不主动扩张。
只有真实使用证据证明其价值后，才增加范围或迁移到更复杂的数据层。

## 5. 当前风险

| 风险 | 影响 | 当前处理 |
| --- | --- | --- |
| DeepSeek 依赖 API Key 与网络 | 配置失败会阻断真实模型使用 | P1 建立应用内配置和恢复流程 |
| 新增 408 知识多为 `review_pending` | 覆盖完整不等于学科审核完成 | P3 逐项审查，不扩大权威声明 |
| 本地社区没有真实多人验证 | 继续扩张可能浪费维护成本 | 保持维护状态 |
| 单人开发 | 同时扩张课程、社区和平台会稀释质量 | 每阶段只保留一条主线 |
| Playwright Electron 仍有实验性 | 不能单独证明安全和打包可靠 | 结合 Vitest、静态检查与包 smoke |
