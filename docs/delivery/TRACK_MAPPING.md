# 黑客松赛道映射

> 状态：报名材料草案
> 最近复核：2026-07-25

本表只选择 6 个赛道。Kaleidoscope 的主叙事是“一个真实学生困惑 → 多个知识视角 → 可操作课件 → 学习证据 → 社区共建”。每个赛道都应由演示中的具体画面证明，而不是只用愿景描述。

## 选择结果

| 选择 | 赛道 | 主要证据 | 当前边界 |
|---|---|---|---|
| 选 | 灵光：「见自己」——先为自己 Vibe | 产品起点就是创始人学习计算机网络、组成原理时遇到的抽象理解痛点；演示从“看懂递归调用栈”开始 | 目前是面向计算机基础课程的桌面 MVP，不声称已覆盖所有学习者和学科 |
| 选 | 智能少年：不做第一，做唯一 | “知识视角 + 已注册课件 + 结构化交互回流”的组合，不是普通聊天框或题库 | 课件仍需独立教学审查；知识点数量有意保持小而精 |
| 选 | 小红书科技：Build in Public | 社区页面、公开/408/示例大学分区、课程筛选、纯文本投稿、待审核/已通过/已驳回状态 | 当前是本地单用户 MVP，不是云端实时社区；投稿不会自动进入权威知识库 |
| 选 | 秒哒：应用美学 | 万花筒视觉语言、视角切换面板、课件 overlay、motion 动效、reduced-motion、清晰的加载/错误/确认状态 | 最终品牌动效、AE 开场与宣传素材仍需在发布前补齐 |
| 选 | superun.ai：Context to Code | 创始人同时是目标用户和问题观察者；Main-only RAG 让计算机学习问题获得真实 chunk 引用或明确 `not_found` 降级 | 调用栈不强绑无关 ODS 知识点，只绑定真实 408 `concept_id` |
| 选 | 涂鸦智能：破界者——用 AI 重写生活脚本 | 把“读书—听课—背诵—刷题”改成“对话诊断—旋转视角—操作课件—记录证据—继续教学”的可运行桌面流程 | 方案是软件学习工具，没有 AI 硬件或 IoT 组件；真实生活问题聚焦学习困难 |
| 不选 | Qoder：一个人 = 一支工程团队 | 工程效率不是 Kaleidoscope 的核心用户价值，不能代表主要产品差异 | 可在技术附录提到 AI 辅助开发，但不将其作为赛道主叙事 |

## 逐赛道报名叙事

### 1. 灵光：先为自己 Vibe

**一句话证据**：我先为自己做了一个能把抽象计算机知识“看见”的学习环境。

**演示画面**：对话首页发送“我知道递归会调用自己，但不明白调用栈到底怎么变化”，AI 诊断后推荐调用栈课件；用户确认后在多个视角间切换。

**万花筒连接**：先看见自己的困惑，再旋转同一个知识点的观察镜面。

**不要声称**：已经实现完全脱离老师和书本的全学科自学。当前证据是一个稳定的计算机基础学习闭环。

### 2. 智能少年：不做第一，做唯一

**一句话证据**：我们没有重新发明一个聊天模型，而是把 AI 对话、标准知识、受约束课件和学习证据组合成独特的教学环境。

**演示画面**：调用栈的定义/直觉/流程/对比/做题/易错/可视化七个注册视角；完成预测后，结构化结果回到同一对话教学上下文。

**万花筒连接**：材料是同一条知识事实，独特性来自镜面和排列关系。

**不要声称**：AI 可以自由生成课件源码。AI 只能选择注册 ID 并生成通过 Schema 的安全参数或补丁。

### 3. 小红书科技：Build in Public

**一句话证据**：学习者可以把自己验证过的解释、类比、易错点、做题方法和考试大纲提交给社区，并看到审核状态。

**演示画面**：进入“示例大学计算机社区”，提交一条纯文本“TLB 和 Cache 的区别”或“考试大纲”，状态从“待审核”改为“已通过”。

**万花筒连接**：每个人贡献一个理解碎片，审核后成为可追溯的候选内容。

**不要声称**：社区内容已经自动进入标准知识库。当前实现保留来源、版本和审核状态，并明确隔离权威知识域。

### 4. 秒哒：应用美学

**一句话证据**：学习体验的价值不只是答案正确，还在于用户是否愿意观察、操作和持续理解。

**演示画面**：视角面板的 tab/左右旋转、课件 workspace 的进出过渡、节点状态颜色和社区卡片；可展示 `artifacts/` 中的界面截图作为辅助。

**万花筒连接**：知识碎片不变，视角切换触发重新排列；视觉变化服务于理解，不是换皮肤。

**不要声称**：最终视频和品牌资产已经交付。AE 开场、宣传截图和最终动效仍是发布前待办。

### 5. superun.ai：Context to Code

**一句话证据**：最接近学生学习问题的人，能把自己的上下文直接转成可运行的教学软件。

**演示画面**：RAG 回答展示本轮检索到的 ODS chunk 标题/章节；检索不到调用栈知识时明确显示“知识库暂无匹配内容”，不伪造出处。

**万花筒连接**：同一标准知识通过不同解释视角和受约束课件形成可操作的学习路径。

**不要声称**：已具备云端 embedding、向量数据库或全课程 RAG。当前是 Main-only 的轻量检索和可验证引用。

### 6. 涂鸦智能：破界者

**一句话证据**：AI 重写的不是一段代码，而是学生解决学习困难的日常脚本。

**演示画面**：从“读书看不懂”进入对话，切换知识视角，操作预测课件，回到同一对话，再进入学校社区。

**万花筒连接**：多个离散的学习动作被排列成一个可运行、可验证、可积累的整体。

**不要声称**：已做 AI 硬件或物联网产品。当前“真实生活问题”明确聚焦计算机课程学习中的抽象、混淆和复习成本。

## 统一结尾文案

> Kaleidoscope 不改变知识本身，只改变观察知识的角度、排列方式和学习路径。一个学生的困惑可以被 AI 诊断，变成多个理解镜面、一个可操作课件和一条有证据的学习路径；更多学习者的经验，则可以在审核后汇入社区。

## 证据与未完成项

- 当前真实实现：10 个注册课件、调用栈七视角、结构化课件交互回流、本地社区审核、Main-only 知识库检索与引用、Electron 安全边界。
- 已完成人工验收：10 个课件独立教学审查，注册状态均为 `reviewed`。
- 需要人工验收：最终真实环境演示、旁白节奏和视觉素材一致性。
- 尚未完成：最终 GitHub Release 和最终演示视频。
- 不作为黑客松阻塞项：DeepSeek 正式 Provider、云端多人社区、文件上传、商业级掌握度模型、硬件接入。
