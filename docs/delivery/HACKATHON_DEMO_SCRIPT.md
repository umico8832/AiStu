# 黑客松演示脚本与验收清单

> 状态：待最终录制
> 最近复核：2026-07-25

本文是当前桌面端实现的 3–5 分钟演示脚本。它描述可在本机复现的路径，不把最终
GitHub Release 或最终视频写成已完成。

## 演示前准备

建议使用全新的临时用户数据目录，避免上一次演示留下的对话或社区投稿影响画面。开发演示使用确定性的本机 Demo Provider：

```bash
KALEIDOSCOPE_AI_PROVIDER=demo pnpm dev
```

如果演示打包产物，先完成项目规定的质量门和 macOS 包检查；打包应用需要携带 `resources/knowledge_base/rag/chunks.jsonl` 快照。最终发布前仍需单独完成 GitHub Release。

## 3–5 分钟黄金流程

### 0:00–0:25｜从真实困惑开始

1. 打开 Kaleidoscope，停留在没有消息的对话首页。
2. 点击快捷问题“看懂递归调用栈”，或在输入框发送：

   > 我知道递归函数会调用自己，但不明白调用栈到底怎么变化。

3. 旁白：

   > 我自己在学习计算机基础课时遇到过这个问题。文字能给定义，却不一定让我看见每一层调用如何等待和返回。Kaleidoscope 先定位困惑，再选择合适的理解方式和课件。

验收点：消息列表出现用户消息和 AI 回答；空状态在产生消息前不滚动，产生消息后消息视口可滚动。

### 0:25–0:55｜展示知识库边界和课件确认门槛

1. 指出 AI 回答下方的知识来源状态。调用栈只绑定真实的 408 知识点；本轮检索命中
   时显示对应 chunk 标题和章节，没有可靠匹配时明确显示“知识库暂无匹配内容”。
2. 等待“可选互动课件”建议卡出现，先点击“暂不”。说明 AI 的 `open_visualization` 只生成建议，拒绝不会打开课件。
3. 再发送：“递归调用栈的返回顺序还是不明白。”等待建议卡后点击“打开课件”。

验收点：用户未确认前 `role=dialog` 的课件 workspace 不可见；确认后才创建当前 session。AI 输出的课件 ID 必须来自静态注册表，场景参数显示“场景参数已校验”。

### 0:55–1:50｜旋转同一个知识点的理解视角

1. 在“栈与函数调用”课件顶部展示“换一个角度理解”面板。
2. 依次点击“定义”“直觉”“流程”“易错”（也可用左右切换按钮）。强调：知识事实没有被改写，变化的是表达和观察顺序。
3. 在课件中按“查看下一步”推进，观察递归调用的入栈、等待、基线返回和逐层返回；在预测暂停点完成一次预测。
4. 旁白：

   > 万花筒里的材料没有变，旋转的是镜面。这里的七种已注册视角分别对应定义、生活化直觉、时间流程、概念对比、考试问法、易错点和可视化操作。

验收点：视角选择只使用注册的 `LearningLens` 枚举；课件代码面板只读；动画支持 reduced-motion；预测、步骤和完成事件作为结构化学习事件记录，不会自动伪装成用户消息。

### 1:50–2:20｜回到同一对话，展示单一课件生命周期

1. 点击“关闭并返回对话”。
2. 指出原用户消息、AI 回答和输入草稿仍在同一会话。
3. 发送：“ArrayQueue 的循环数组回绕怎么理解？”确认建议后打开 ArrayQueue 课件；快速展示公式 `a[(j + k) mod 8]`，随后关闭。
4. 可选：再打开 ArrayStack 按位插入或 DualArrayDeque 再平衡，说明新请求会替换当前活动页面，不创建第二个标签页或课件栈。

验收点：应用任意时刻只有一个 `activeSession`；同一课件更新 revision，不同课件原子替换；课件关闭后对话不会被销毁。

### 2:20–3:05｜社区共建最小闭环

1. 打开导航，进入“社区共建”，先展示“408 备考社区”或“示例大学计算机社区”。
2. 指出已有的已通过投稿和待审核投稿；筛选器可按课程、社区和审核状态过滤。
3. 点击“分享一个发现”，填写一条纯文本内容，例如：

   - 标题：`TLB 和 Cache 的区别`
   - 内容类型：`易错点`
   - 课程：`计算机组成原理`
   - 社区：`示例大学计算机社区`
   - 昵称：`演示学习者`
   - 内容：`TLB 缓存地址映射，Cache 缓存数据或指令；做题时先判断题目问的是地址转换还是数据访问。`

4. 点击“提交审核”，展示“待审核”状态；再点击该投稿的“通过”，展示“已通过”。
5. 旁白：

   > 社区贡献是候选内容，不会自动改写权威知识库。当前是本地、单用户的审核闭环；学校社区和考试大纲以结构化纯文本投稿演示，尚不是云端实时协作或文件上传系统。

验收点：投稿 Schema 拒绝 HTML、脚本协议和事件属性；状态只允许 `pending_review`、`approved`、`rejected`；通过内容仍带有来源和审核状态。

### 3:05–3:50｜收束主题与安全边界

1. 返回对话首页，展示一句总结：

   > Kaleidoscope 不改变知识本身，只改变观察知识的角度、排列方式和学习路径。

2. 如果时间允许，打开课件后用开发者验收脚本/Playwright 证明：Renderer 中
   `process` 与 `require` 均为 `undefined`，`window.kaleidoscope` 只暴露
   `chat`、`knowledge` 和 `persistence` 领域 API。
3. 结束语：

   > 从一个学生自己的困惑出发，AI 把同一知识点组织成多面镜，再用可操作课件把交互结果带回同一段教学对话。

## 演示完成判定

### 已实现、可演示

- 对话首页、Demo Provider 流式回答、停止/重试和最小会话持久化；
- Main-only 知识库检索、`grounded`/`not_found`/`unavailable` 状态和可验证 chunk 引用；
- 10 个已审查静态注册课件：调用栈、三项 ODS 课件和六项 408 核心过程课件；
- 课件建议卡、用户确认门槛、单一活动可视化、关闭回到对话、结构化交互事件；
- 调用栈的 7 个受约束学习视角和可视化 workspace 面板；
- 本地社区投稿、学校分区、课程/状态筛选、审核通过/驳回和 localStorage 持久化；
- Electron `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`、CSP、导航/新窗口/权限拦截和最小 preload API；
- typecheck、lint、Vitest、Playwright、build、macOS arm64 `package:dir`、快照完整性和启动 smoke（以最近一次基线记录为准）。

### 现场仍需人工确认

- 黑客松现场使用的真实 Provider、网络环境、窗口尺寸和 reduced-motion 偏好；
- 真实场景演示中的旁白、截图和转场节奏；
- 打包应用启动后，知识库快照和活动课件恢复是否与本机演示数据一致。

### 尚未完成，不应在报名材料中写成已交付

- 最终 GitHub Release（包含最终 `.dmg`/`.zip` 链接）；
- 最终 3–5 分钟演示视频和配套 AE 素材；
- 正式 DeepSeek API Provider、云端多人社区、文件上传和商业级知识追踪（均不属于当前黑客松阻塞项）。
