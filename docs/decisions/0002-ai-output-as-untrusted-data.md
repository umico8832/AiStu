# ADR-0002：AI 输出只作为不可信数据

- 状态：accepted
- 日期：2026-07-25

## 背景

AI 需要选择课件、调整示例并提出教学提示，但模型输出不可预测，也可能包含错误、
未知字段、伪造引用、源码或注入内容。允许模型生成并执行页面代码会把教学系统变成
动态代码执行平台，破坏 Electron 隔离和课件审核。

## 决策

- AI 文字与应用控制命令分离；
- 命令、session spec、patch、引用与快捷回答使用共享严格 Schema；
- 课件来自本地静态注册表，AI 只能选择 ID；
- 课件场景先经过通用外层和课件专属 Schema；
- patch 只允许预先声明的判别联合，并校验 session、ID 和 revision；
- 引用只允许来自本轮检索候选集合；
- AI 文本通过受限 Markdown 语义渲染，不解析模型 HTML；
- AI 不能指定源码、模块、组件路径、文件路径、任意 URL 或属性路径；
- 校验失败时保持当前状态、使用审核默认场景或回退文字讲解。

## 后果

优点：

- 安全边界可测试、可审计；
- 课件教学质量可独立审核；
- Provider 可以替换而不改变 Renderer；
- 非法输出有确定降级路径。

代价：

- 每项课件必须设计专属 Schema 和有限能力；
- 新教学表达需要开发并审核资源，不能由模型临时创造任意 UI；
- 结构化输出与版本迁移增加工程工作。

## 被否决方案

- 执行 AI 生成 React/JavaScript：安全与可维护性不可接受；
- AI 提供动态 import 路径：绕过注册表与审核；
- 任意 JSON props 直传组件：无法限制复杂组件输入；
- 只依赖 Prompt 约束：不能替代运行时验证。
