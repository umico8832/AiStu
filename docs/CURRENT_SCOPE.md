# AiStu 当前开发范围

> 状态：当前交付范围
> 最近复核：2026-07-27
> 本文定义 0.2 阶段做什么和怎样验收。长期方向见
> [`PRODUCT_DIRECTION.md`](PRODUCT_DIRECTION.md)，真实进度见
> [`ROADMAP.md`](ROADMAP.md)。

## 1. 阶段目标

把已经跑通的桌面教学闭环变成可以持续日常使用的个人 AI 学习工具。

本阶段不再服务比赛演示，也不围绕品牌隐喻扩展功能。优先级由真实学习价值、
稳定性和单人维护成本决定。

## 2. 范围内

### 2.1 身份与产品基线

- 产品、包、协议、环境变量和文档统一使用 `AiStu`；
- 应用图标表达 AI 辅助学习，不由名称派生额外装饰或功能；
- 页面文字只服务当前操作、状态和错误恢复。

### 2.2 日常使用可靠性

- Provider 配置、错误提示、停止和重试形成可恢复流程；
- 会话、课程记录、错题和课件状态在异常退出与版本升级后可靠恢复；
- 用户数据具备可验证的导出、备份和恢复路径；
- 关键迁移、持久化和窗口生命周期具备自动化回归测试。

### 2.3 学习延续

- 用户可从最近会话、课程记录或错题继续学习；
- 复盘只携带必要上下文，并记录真实重试结果；
- 课程页给出由现有学习记录支持的下一步入口；
- 浏览、时长和自评仍不得自动判定为掌握。

### 2.4 教学质量

- 用真实失败案例维护 Tutor 回归样例；
- 事实型回答继续受知识检索与引用约束；
- 只有高频、适合交互且完成独立审查的内容才新增课件；
- 解释方式由具体问题决定，不维护固定的展示分类体系。

## 3. 维护状态

以下已实现能力继续维护，但不作为本阶段扩张主线：

- 全国考试目录与内容商店；
- 本地社区讨论和题库投稿；
- 现有 408 数据结构知识与 10 项互动课件；
- Demo Provider 和发布演示场景。

## 4. 暂不进入

- 云端多人社区、关注和私信；
- 商业级掌握度与自动复习算法；
- 大规模新增课程或互动课件；
- 插件系统、IDE、终端和 AI 动态前端源码；
- 为宣传或视觉完整度增加没有学习价值的页面；
- Windows 正式发布、Developer ID 签名和公证。

## 5. 安全与架构条件

- Electron 继续保持 `nodeIntegration: false`、`contextIsolation: true`、
  `sandbox: true`；
- Main、Preload、Renderer 的职责和数据域边界不得放宽；
- AI 输出、知识内容、社区内容和跨进程输入继续按不可信数据处理；
- 新能力必须使用最小、强类型、可校验的领域 API。

## 6. 阶段验收

- 应用中不存在旧产品名称和旧主题组件；
- Provider 常见失败可以在界面内恢复；
- 会话与学习记录经过异常退出和升级恢复测试；
- 用户能从一次学习自然进入后续复盘；
- 新增 Tutor 行为有失败样例和回归测试；
- `pnpm typecheck`、`pnpm lint`、`pnpm docs:check`、`pnpm test`、
  `pnpm test:e2e` 和 `pnpm build` 通过；
- macOS 应用从当前工作树打包并启动验证。
